# Changelog

## 0.3.0 preview

First public source release under GPL-3.0-only.

- Native preset library, response preview and expandable 16-band editor.
- Strict Equalizer APO text / JSON import, JSON / APO export, copying and local persistence.
- Original/EQ comparison with the same preamp, 25 ms transitions, automatic headroom and clipping indicators.
- Core Audio device-bound system tap, menu bar controls, output / rate change and sleep pause behavior.
- Optional 10-second route check with automatic attenuation restoration.
- Universal macOS app build, automated numerical / callback checks and GitHub Actions validation.

The public distribution contains original generic examples only. Measurement-author presets are kept outside the source distribution. The downloadable preview is Developer ID signed and **not Apple notarized**.
